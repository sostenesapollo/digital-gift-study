# Estudo: 179.297 presentes digitais

Página do estudo de dados sobre 18 meses de presentes digitais criados no [Gifts QR](https://giftsqr.com).

**Leitura:** https://sostenesapollo.github.io/digital-gift-study/

## Conteúdo

- `index.html` — a página do estudo, sem dependências, sem build
- `data/*.csv` — séries brutas usadas nos gráficos

## Números principais

| Indicador | Valor |
|---|---|
| Presentes criados (abr/2025 – nov/2026) | 179.297 |
| Concentração nos últimos 6 meses | 96,1% |
| Aniversário | 38,4% do total |
| Pico horário | 15h UTC (12h em Brasília) |
| Pico semanal | sábado, 29.778 |
| Conversão para pagante | 2,03% |
| Presentes com QR code gerado | 3.418 (1,9%) |

## Metodologia

Contagem direta do banco de produção. Uma "página de presente" é um registro criado por visitante, independente de ter sido enviado ou aberto. Fuso horário UTC. Sem projeções.
